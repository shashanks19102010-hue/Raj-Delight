# Raj Delight

Premium, responsive restaurant website for Raj Delight, Chandausi.

## V4 highlights
- Mobile-first responsive layout with overflow-safe edge decorations
- Light/dark theme switch
- Direct phone contact and Instagram `@raj_delight`
- Zomato and Swiggy ordering links
- Complete public menu with search and category filtering
- Public spend snapshot and transparent live-price links
- Refined RD brand emblem inspired by the supplied reference image
- Editorial gallery with public-listing disclosure for third-party imagery
- Reduced-motion support and accessible labels

## Data note
The public ordering page exposes menu names but currently gates individual dish prices behind login, so the site does not invent item prices. Public listing-level spend information is shown where available.

## Run locally
```bash
npm install
npm run dev
```

## Validate
```bash
npm run typecheck
npm run build
```
