# Raj Delight — Luxury Indian Editorial Design System

## Direction

Raj Delight uses a restrained luxury-editorial language: Indian heritage translated through contemporary typography, warm photography, generous whitespace and precise interaction design.

## Palette

- Ivory `#F5F0E6` — primary canvas
- Paper `#FBF7EF` — elevated light surfaces
- Espresso `#17120E` — primary dark surface
- Burnished Gold `#BD9650` — accents and interactive emphasis
- Soft Gold `#E2C384` — display accents
- Terracotta `#8A4B32` — optional editorial warmth
- Muted `#756B60` — secondary copy

## Typography

- Display: Cormorant Garamond, Semibold / Italic
- UI: DM Sans
- Long-form supporting copy: Georgia/system serif fallback where a calmer reading texture is preferred

## Layout

Use a 12-column editorial grid on desktop. Keep a consistent content width around 1240px, generous section spacing, strong horizontal rules and deliberate asymmetry. On mobile, reduce to a single-column reading flow with two-column cards only where content remains legible.

## Motion

Motion should be quiet and physical rather than decorative:

- Hero image: slow 1–3% ambient scale
- Desktop hero: pointer parallax constrained to a few pixels
- Section entrances: opacity + 20–30px upward reveal
- Images: 1.04–1.08x hover scale with long easing
- Buttons: 2–3px lift
- Menu rows: height/opacity transition
- Gallery: image scale + restrained caption overlays
- Marquee: slow continuous editorial ticker
- Scroll progress: 2px top-edge scale indicator
- Reduced motion: disable ambient loops and non-essential transitions

## Interaction rules

Use one strong primary action per section. Avoid gratuitous gradients, particles, 3D objects, excessive glassmorphism, or constant movement. Motion exists to guide attention and establish atmosphere.

## Content rules

Preserve the complete public menu and existing ordering destinations. Do not invent restaurant claims, prices, ratings, licences, or operating facts that are not supported by the source data.

## Figma

The companion design file is **Raj Delight — Luxury Editorial Design System**. It contains the visual foundation, desktop/mobile art-direction boards, and reusable components for CTA, menu category rows and signature dish cards.

## Canva

Canva is reserved for brand/content collateral rather than core website UI: social posts, seasonal campaign artwork, menu graphics and OpenGraph/marketing creatives. No Canva brand kit is currently connected.
